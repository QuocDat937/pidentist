## PROMPT 6.7 — Accessibility final audit

```
Chạy audit accessibility và fix:

### Checklist:
1. Skip-to-content link ẩn → hiện khi focus (đã có trong header.php)
2. Tất cả <img> có alt text mô tả
3. Tất cả <a> có aria-label hoặc text rõ ràng
4. Form fields có <label> liên kết
5. Color contrast: text trên navy ≥ 4.5:1, text trên white ≥ 4.5:1
6. Keyboard navigation: Tab qua tất cả interactive elements
7. Focus visible: outline rõ ràng khi tab
8. ARIA landmarks: <main>, <nav>, <footer>, <header>
9. Heading hierarchy: H1 > H2 > H3 không skip level
10. prefers-reduced-motion: tắt animation

### Fix common issues:
- Thêm aria-label cho icon-only buttons (hamburger, back-to-top, social icons)
- Thêm role="navigation" cho nav
- Thêm aria-expanded cho dropdown menus
- Ensure sufficient color contrast cho .hero-sub (rgba white 0.8 trên navy)

### Test tools:
- Lighthouse Accessibility score target: ≥ 95
- axe DevTools extension
- WAVE Web Accessibility Evaluator
```
